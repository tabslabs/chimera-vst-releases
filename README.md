# Chimera

Free physical-modeling vocal instrument for VST3 and CLAP hosts.

[Download for macOS (Apple Silicon + Intel)](https://github.com/tabslabs/chimera-vst-releases/releases/latest/download/Chimera-macOS-universal.dmg)

[Download for Windows x64](https://github.com/tabslabs/chimera-vst-releases/releases/latest/download/Chimera-windows-x64.zip)

[All releases and checksums](https://github.com/tabslabs/chimera-vst-releases/releases)

Play a modeled human voice; trigger speech, sing typed lyrics, play songbird/seal/alligator/elephant calls, or sequence mouth drums with MIDI. Settings, speech and lyrics are saved with your DAW project.

Downloads contain both plugin formats, installation instructions and license notices. macOS builds are Developer ID signed and notarized. Windows builds require WebView2 Runtime for the editor; see each release for signing status. Windows DAW compatibility still needs manual validation.

This repository hosts downloads only. Chimera is derived from [jamesondh/chimera-vocal-synth](https://github.com/jamesondh/chimera-vocal-synth); the original MIT notice is included with every download.
